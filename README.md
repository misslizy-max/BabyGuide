# BabyGuide

Мобильная семейная PWA на русском языке для родителей детей 0–36 месяцев: персональный день родителя и отдельный защищённый детский режим. React, TypeScript, Vite, локальные дневники и IndexedDB для аудио. Без аккаунта, рекламы и серверной базы данных.

## Запуск и проверки

Node.js 22.12+ или 24 LTS (также поддерживается 20.19+), npm:

```sh
npm ci
npm run dev
```

Проверка production / offline:

```sh
npm run build
npm run preview -- --port 4173
```

```sh
npm run typecheck
npm test
npm run test:e2e
```

Playwright использует `CHROMIUM_PATH`, затем системный `/usr/bin/chromium`, затем установленный Playwright Chromium. Если браузера нет:

```sh
npx playwright install --with-deps chromium
```

Браузерные тесты сами запускают и останавливают preview на 4173. Не занимайте этот порт другим процессом во время тестов. Для аудиопроверок используется тестовое аудиоустройство Chromium; приложение использует обычные getUserMedia и MediaRecorder. GitHub Actions запускает проверки на push/PR.

## Режим «Мама»

Нижняя навигация: **Главная / Дневник / Рекомендации / Ещё**. В шапке — профиль, детский режим и красные флаги.

- Главная: имя, точный возраст, последние измерения, сон за 24 часа, записи питания за день, подходящая игра, текущий этап развития, погода/одежда, практикум и локальные напоминания.
- Профиль: дата рождения, пол, страна/город/регион продуктов, питание, аллергии, исключения, введённые/любимые/нелюбимые продукты, запасы дома, навыки, любимая игрушка и заметки. Метрики хранятся в общей истории, а не дублируются в профиле.
- Развитие: все 37 месяцев от 0 до 36; 8 областей, упражнения, игры и красные флаги. Контрольные возраста CDC явно отделены от промежуточных редакционных идей. Это не календарь обязательных достижений.
- Игры: **70** разных игр в 10 категориях; возраст, цель, материалы, подготовка, шаги, длительность, сложность и безопасность. Фильтры по возрасту, навыку, времени и материалам.
- Питание: **52** рецепта, **14** разных дней меню, безопасная подача 6/7/8/9/10/11/12+ месяцев, gagging vs удушье. В рецепте — иллюстрация, граммовки, шаги, время, текстура, аллергены, ограничения и замены.
- Конструктор: возраст и ограничения — жёсткие фильтры; запасы, предпочтения, регион и сезон — приоритеты. Есть строгие фильтры «только дома» и «только введённые». «Заменить», «другое блюдо», «нет продукта» и «не нравится» меняют отдельное блюдо. При отсутствии безопасного варианта приложение объясняет причину, а не игнорирует аллергию.
- Региональные профили: Россия, Дальний Восток, Европа, Средиземноморье, Восточная Азия, Северная Америка. Временный город поездки отделён от домашнего. Это продуктовые предпочтения и типичные замены, а не информация о наличии в магазине.
- Сон: история, длительность, временная шкала, сумма сна в выбранные сутки, переход через полночь и защита от пересекающихся записей.
- **12 полных гайдов** с 13 разделами и сохраняемыми практикумами на 3/7/14 дней: засыпание, пробуждения, split night, ранние подъёмы, короткие сны, отказ/переход, бутылочка, ритуал, горшок, речь и безопасность дома.
- Рост: вес, длина/рост и окружность головы, история, изменение за период, WHO P3/P50/P97 и справочный процентиль. Используются реальные ежедневные LMS-таблицы, а не нарисованные нормативы. [Происхождение данных](docs/WHO-DATA.md).
- Здоровье: температура, ОРВИ, насморк, кашель, горло, уши/ЛОР, зубы, рвота, диарея, обезвоживание, сыпь, ожоги, падения, аллергия, первая помощь и красные флаги. Нет постановки диагноза.
- Температура: время, способ измерения, состояние, фактический приём лекарства и график за сутки. Калькуляторы парацетамола/ибупрофена требуют возраста, актуального веса, концентрации с упаковки и проверки ограничений. Показывают формулу и консервативный предел частоты по указанным источникам. До 6 месяцев и вне диапазона 6–36 расчёт не применяется.
- Единая лента: сон, еда, смесь, температура, лекарство, измерения, навык, слово, заметка; фильтрация по типу.
- Глобальный поиск: статьи/симптомы, гайды, игры, рецепты, месяцы развития, потешки и истории. Избранное для этих материалов.
- Библиотека источников: WHO, CDC, AAP, AASM, ASHA, NHS, RCH и Open-Meteo с объяснением, какая часть приложения основана на каждом.

## Режим «Ребёнок»

Нет ссылок наружу, покупок, рекламы и родительской навигации. Режим переживает перезагрузку, а переход на родительский hash не раскрывает настройки. Выход — через задачу для взрослого. Это защита от случайных нажатий малыша, не механизм аутентификации против старших детей.

- **54** крупные карточки / 9 категорий, свайп, слово и системная озвучка; животные и транспорт — голосовые звукоподражания.
- «Где…?» с 4 вариантами, позитивной реакцией, короткой анимацией и звуком.
- Мяч, пузыри, коробочка и музыкальные клавиши — реальные причинно-следственные интерактивы.
- **20** полных авторских потешек с движениями и аудиорежимом.
- **17** авторских поддерживающих историй: сон, темнота, врач/стоматолог, горшок, разлука, сад, знакомство, поездка/перелёт, эмоции, ревность, еда, вода, стрижка и больница. Имя и игрушка берутся из профиля. Страницы с иллюстрациями, чтением и озвучкой. Истории не заявлены как лечение расстройств.
- «Повторюшка»: явное разрешение, состояния слушания/повтора, автоматическая остановка после паузы или максимум 8 секунд; микрофон останавливается **до** воспроизведения. Нет feedback loop. Обычный / смешной голос / «скажи слово». Тон/скорость меняются при поддержке браузером.
- Несохранённая запись живёт только в памяти, удаляется после повтора или выхода. Сохранение в «Мои первые слова» — отдельное действие родителя: слово, дата, возраст, аудио, комментарий.

Для малышей до 18 месяцев предпочтительны занятия без экрана, кроме общения с близкими. В любом возрасте — короткие совместные игры со взрослым, а не длительный самостоятельный экран.

## Приватность, хранение и резервная копия

`localStorage` (`babyguide.v2`) хранит профиль и события. IndexedDB (`babyguide.audio`) — только явно сохранённые аудиозаписи. Данные прежней версии `babyguide.v1` мигрируют при чтении; исходный ключ не удаляется до явного сброса. Детский режим хранит отдельный флаг `babyguide.child`.

Данные привязаны к origin браузера, включая порт: dev, preview и опубликованный домен имеют разные хранилища. Между ними переносите данные через экспорт/импорт JSON **с аудио**. Импорт проверяется и требует подтверждения замены. Повреждённый файл отклоняется. При ошибке записи приложение не сообщает об успешном сохранении. Очистка браузера/сайта может удалить всё: регулярно экспортируйте копию.

Записи микрофона не отправляются на сервер. Камера не запрашивается. Геолокация — только по соответствующей кнопке; ручной город работает без неё. Нет аналитики и внешних шрифтов. Проигрывание речи использует системный SpeechSynthesis: доступность русского офлайн-голоса зависит от устройства. Это не набор заранее записанных дикторских или натуральных звуков животных.

## Погода и сеть

Без ключей API используются `geocoding-api.open-meteo.com` (город/страна) и `api.open-meteo.com` (погода). Запрашиваются температура, ощущаемая температура, ветер, осадки, влажность и дневной максимум UV. Неполные/ошибочные ответы не выдаются за прогноз. Есть повтор, ручной выбор и обработка запрета геолокации, неверного города, тайм-аута и отсутствия сети.

Одежда показывается шестью слоями: база, утепление, верх, ноги/обувь, головной убор, дополнительные элементы. Коляска и активная прогулка различаются; ветер, осадки, UV, жара и холод добавляют условия. Это бытовые ориентиры, не гарантия комфорта без оценки ребёнка.

При ограниченной сети разрешите оба домена. Последняя реальная проверка установила: npm и GitHub доступны, оба домена Open-Meteo отклоняются прокси (`403 Forbidden` при CONNECT; в Chromium — `ERR_TUNNEL_CONNECTION_FAILED`). Политика среды `enforced`, пользовательский allowlist пуст. Поэтому успешный живой прогноз **не подтверждён**. Сохранённого черновика настроек недостаточно — разрешения нужно применить к работающей среде.

После применения разрешений выполните отдельную проверку **без подмены API**:

```sh
npm run test:weather:live
```

Она проверяет настоящий ручной поиск, неизвестный город, независимый запрос прогноза по координатам, одежду по полученным данным и потерю сети. Проверки API намеренно завершаются ошибкой, если реальный ответ не получен. В последнем запуске: 3 сетевых сценария заблокированы, сценарий потери сети прошёл. Контролируемые API-тесты из обычного e2e-набора не подменяют этот результат. Отдельный preview использует порт 4183, результаты сохраняются в игнорируемый `live-test-results/`. Запускайте этот набор последовательно с обычным e2e: оба используют production-сборку `dist/`.

## Архитектура

```text
src/
  App.tsx                    # маршрутизация, родительская оболочка, граница режимов
  components/UI.tsx          # общие семантические компоненты, графики, озвучка
  screens/                   # родительские разделы, питание, погода, аудио, ребёнок
  hooks/                     # состояние, погодный store, жизненный цикл микрофона
  data/                      # типизированные игры, рецепты, гайды, истории, источники
  services/                  # схема/миграция, IndexedDB, меню, WHO, лекарства, погода
  types/                     # доменная модель
  utils/dates.ts             # возраст, локальные даты, объединение интервалов сна
  content.js, development.js  # сохранённые базовые справочные данные первой версии
  storage.js                 # валидатор прежнего формата для миграции
  visuals.js                 # собственная SVG-иллюстрация
  style.css, product.css     # пастельная система, адаптивность, rem, safe area
  service-worker.js          # шаблон версионированного offline app shell
public/
  manifest.webmanifest
  icons/                     # 192/512, maskable, Apple Touch Icon, SVG
  licenses/                  # лицензия источника WHO-таблиц
```

Vite отдельно собирает React vendor, WHO-данные и приложение; service worker предзагружает все необходимые модули. В development service worker выключен, чтобы не скрывать изменения кэшем. Нет параллельной старой HTML-реализации.

## PWA и публикация

Публикуйте `dist/` **в корне HTTPS-домена**. Hash-маршрутизация не требует серверных маршрутов статей. Текущие абсолютные пути не рассчитаны на подпапку `/BabyGuide/` GitHub Pages: для неё нужно согласованно изменить base, manifest/scope и service worker URL.

Для `index.html` и `sw.js` используйте `Cache-Control: no-cache`, для хешированных assets — immutable-кэш. Новая версия активируется после закрытия старых вкладок. Service worker удаляет только собственные устаревшие кэши, не кэширует персональные данные и динамические погодные ответы. Справочник, гайды, меню, игры, карточки и дневники работают офлайн после первой успешной загрузки production-сборки.

На iPhone: Safari → «Поделиться» → «На экран Домой». HTTPS нужен для PWA и разрешений; localhost допустим для разработки. Проверка Chromium с размерами iPhone не доказывает работу установки, системного голоса и записи Safari на физическом устройстве. Их нужно отдельно проверить перед выпуском.
