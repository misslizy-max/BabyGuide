# WHO Child Growth Standards

Числовые LMS-таблицы для возраста 0–1096 дней (вес, длина/рост, окружность головы), оба пола. Источник: официальный репозиторий WorldHealthOrganization/anthro, commit b776d8a12b1c97369c748b561159fd2ec4f4db58.

https://github.com/WorldHealthOrganization/anthro/tree/b776d8a12b1c97369c748b561159fd2ec4f4db58/data-raw/growthstandards

Данные отобраны по возрасту без изменения L/M/S. Индекс строки JSON равен возрасту в днях. Для графика берётся ежемесячная выборка; для расчёта используется точный целый день. Измерение длины до 2 лет лёжа, после — роста стоя, согласно исходной таблице. Недоношенность, ошибки измерения и клинический контекст приложение не корректирует автоматически.
