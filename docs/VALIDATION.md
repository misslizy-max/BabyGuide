# BabyGuide 2.0 · проверка реализации

## Осмотр исходного состояния

Перед мастер-спецификацией репозиторий уже содержал подготовленную PWA 1.0, а не пустой README. Проверены Git, package/lockfile, все модули, источники, manifest, service worker, CSS, тесты и документация. Изменения первого прохода не были отправлены в GitHub; HEAD оставался первоначальным. История осмотра и решения: [PRODUCT-COVERAGE.md](PRODUCT-COVERAGE.md).

Строковый интерфейс заменён React/TypeScript. Справочные данные сохранены, формат `babyguide.v1` мигрирует в `babyguide.v2`. Legacy validator покрыт отдельными тестами. Миграция не требует сброса данных. Аудио отделено от JSON-дневников в IndexedDB.

## Автоматические проверки

Полный прогон после чистого `npm ci`: **18/18 проверок логики и 23/23 браузерных сценариев прошли**, strict typecheck и production build успешны, `npm audit` — **0 уязвимостей**.

### Логика и типы

- TypeScript strict + noUnusedLocals/noUnusedParameters для TS/TSX; production build включает typecheck.
- Миграция старых дневников, сна, измерений и избранного, валидация резервной копии и повреждённых значений.
- Даты и возраст, сон через полночь, пересечение с выбранными сутками и объединение дублей.
- Состав библиотеки: 37 месяцев / 8 областей, 70 разных последовательностей игр, 52 рецепта / 14 уникальных дней, 12 полноформатных гайдов, 20 полных потешек, 17 историй, 54 карточки.
- Реальная логика меню: аллергия на молоко исключает все молочные блюда; исключения/предпочтения/возраст/введённые продукты/запасы; влияние региона/сезона без запрета ручного просмотра.
- WHO: исходная медиана рождения мальчика 3.3464 кг / 49.8842 см, обращение LMS для всех 3 метрик/обоих полов, выход за границы данных, нормальное CDF для справочного процентиля.
- Лекарства: отсутствие исходных данных, возрастные ограничения, формула мг/мл, контроль частоты. Тестовые результаты не являются назначениями.
- Погодный клиент: кодирование запроса/страна, неполные ответы/ошибки/необязательный UV, 6 слоёв одежды и различие активности. Тайм-аут продолжает работать при внешнем сигнале отмены, его причина сохраняется.

### Playwright / Chromium

- Проход по всем родительским разделам и всем записям статического контента, отсутствие pageerror и горизонтального переполнения.
- Все 37 месяцев, отображение 8 областей и контрольного статуса CDC.
- Профиль со всеми пищевыми настройками, reload, реальные метрики/точный возраст на главной.
- Единая лента: заметка, смесь, температура, фильтры и подтверждение удаления.
- Сон через полночь, правильная суточная часть и запрет пересекающегося интервала.
- Глобальный поиск, 13 секций гайда, сохранение практикума, избранное разных типов.
- Дни меню открывают рецепты. Замена меняет одно блюдо; аллергия и строгие запасы соблюдаются, меню переживает reload.
- Медицинский расчёт отклоняется без возраста, показывает формулу после заполнения вес/концентрация/проверка инструкции.
- Погода с контролируемыми ответами: успешный GPS; запрет и полное отсутствие API геолокации с рабочим ручным поиском; неизвестный город; 503; неполный ответ; offline; влажность/UV; 6 слоёв одежды; поездка → новый домашний город без рассогласования прогноза/региона.
- Детский режим: отсутствие parent nav/внешних ссылок; попытка открыть здоровье и reload не раскрывают родительский экран; неверный/верный взрослый выход.
- Карточки, свайп, правильный ответ в «Где…?», пузыри, коробка, страницы истории.
- **Настоящие браузерные getUserMedia/MediaRecorder/HTMLAudioElement с тестовым устройством Chromium**: явное начало, реальный Blob, остановка дорожек, воспроизведение с растущим currentTime, запись в IndexedDB, reload, backup с аудио.
- Отказ/отсутствие микрофона, удаление transient записи после повтора; остановка по паузе (контролируемый сигнал анализатора); освобождение микрофона при переходе.
- Экспорт/сброс/импорт аудиокопии, повторное воспроизведение, восстановление повреждённого storage; ошибка quota не показывается как успех.
- Manifest/PNG icons, активный service worker, полное отключение сети, reload, все библиотеки и запись дневника офлайн.
- Ширины 320 / 390 / 1440 px, детские экраны 320 px, увеличенный базовый шрифт 24 px (150%). Сделаны screenshots; мобильные родительский/детский экраны и карточки просмотрены визуально.

Погодные сценарии используют контролируемые ответы именно production-клиента; это не подмена данных внутри приложения. Для надёжного перехвата API в этих сценариях service workers заблокированы тестовым контекстом. **Отдельный PWA-сценарий включает service worker** и действительно отключает сеть.

## Найденные и исправленные дефекты

- Повреждённый hash / inherited route names не ломают приложение.
- Выбор домашнего города завершает временную поездку: прогноз, подпись и регион меню согласованы.
- Тайм-аут 12 секунд действует и при внешнем AbortSignal; внешняя отмена сохраняет свою причину.
- Тест сохранения аудио дожидается завершения асинхронного IndexedDB-сохранения перед reload, проверяя появление записи, а не задержку наугад.
- Новые поля профиля и метрики не теряются после перезагрузки.
- Последний замер только головы не скрывает предыдущий вес/рост на главной.
- Автоматически предложенный регион после изменения страны отображается в форме и не откатывается при повторном сохранении профиля.
- Суточный сон считает фактическое пересечение с сутками, а не только дату начала; дубли не удваивают сумму.
- Повреждённый импорт не заменяет текущие данные. После восстановления исходная ошибочная копия не продолжает подставляться вместо нового экспорта.
- Ошибки storage не выдаются за успешную запись; удаление аудиособытия включает удаление Blob и восстановление при неудаче записи JSON.
- При переходе из детского режима на parent hash URL возвращается в child; защиту нельзя случайно снять кнопкой «назад».
- Свайп карточки не должен одновременно озвучивать неправильную карточку.
- У детской «Повторюшки» есть основной заголовок и доступные состояния записи.
- Размеры зон нажатия в шапке увеличены, текст переведён в rem, iOS Dynamic Type и увеличение базового шрифта не вызывают горизонтальное переполнение проверенных экранов.

## Внешние границы приёмки

- **Живой Open-Meteo не прошёл проверку**: прямые запросы поиска Владивостока и прогноза по координатам получили CONNECT `403 Forbidden`; Chromium — `ERR_TUNNEL_CONNECTION_FAILED`. npm HTTP 200 и GitHub Git fetch подтверждены. Runtime: restricted/enforced, custom allowed_hosts=[]; оба погодных домена отсутствуют в действующем разрешении.
- `npm run test:weather:live`: **1 passed / 3 failed / 0 skipped**, exit 1. Прогноз, реальный поиск и неизвестный город заблокированы на подключении; проверка отсутствия сети прошла. Одежда по **живому** прогнозу не подтверждена — прогноз не получен. Одежда по контролируемому API и отсутствие геолокации проверены обычным браузерным набором. После применения доменов нужен повтор live-набора; текущий сетевой отказ не выдаётся за успешную проверку.
- **Физический iPhone/Safari не проверен**. Chromium iPhone viewport не доказывает установку через Share Sheet, системные разрешения/голос, кодек MediaRecorder и длительную работу на iOS. Аппаратный микрофон человека не использовался.
- Синтез речи и смешной голос зависят от возможностей браузера. Натуральные звуки животных не записывались; используются явно обозначенные голосовые звукоподражания.
- Свежесть всех внешних справочных ссылок и независимая клиническая редактура не подтверждаются браузерными тестами. Инструкции препаратов и местные рекомендации имеют приоритет.
- Push, синхронизация, серверные аккаунты и сведения о наличии продуктов в магазинах не заявляются.
- Публикация сайта и snapshot среды не входят в commit/push. CI настроен; список включённых файлов — [RELEASE-FILES.txt](RELEASE-FILES.txt). Результат отправки и SHA сообщаются после подтверждения GitHub.

## Последний независимый проход console / PWA

Отдельный браузерный smoke слушает `pageerror` и `console.error` **до первого открытия** и проверяет загрузку и переходы между родительскими/детскими разделами без искусственных ошибок API. Ожидаемые ошибки сетевых negative-сценариев не смешиваются с чистым console-проходом. PWA-сценарий включает настоящий service worker и полностью отключает сеть. Текущие результаты обычного набора и сетевые результаты учитываются раздельно.
